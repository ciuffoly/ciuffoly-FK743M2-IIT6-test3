# FK743M2-IIT6 + 800x480 RGB LCD 


A minimal STM32CubeIDE project for the FK743M2-IIT6 development board featuring the STM32H743IIT6, external SDRAM and a 800x480 RGB LCD with an image stored in the QSPI.

Extract the project.zip in the root of the project to have the others files.
