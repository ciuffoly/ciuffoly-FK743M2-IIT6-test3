# FK743M2-IIT6 + 800x480 RGB LCD 


A minimal STM32CubeIDE project for the FK743M2-IIT6 development board featuring the STM32H743IIT6, external SDRAM and a 800x480 RGB LCD with an image stored in the QSPI.

Extract the project.zip in the root of the project to have the others files.

Here the my webpage with a <A HREF=https://www.audiodesignguide.com/TouchScreenController/index.html>guide to use STM32</A>

Starting from this source code but the my with another graphic library

https://github.com/fcaussa/FK743M2-IIT6

External loader file to use with ST-LINK to flash QSPI.

https://github.com/republicofmakers/SW-MCU-STM32-ExtLoader-006/tree/main

- STM32H743IIT6  Arm® Cortex®-M7 core frequency up to 480 MHz with 2 MB of Flash memory and Up to 1Mbytes of RAM
- 4.3", 5" or 7" LCD 800x480 connnected in RGB
- LCD parallel interface
- Capacitive touch screen
- 512-Mbit SDRAM
- Boot and reset push-buttons
- MicroSD card
- External ST-LINK/V2 is necessary to flash
- 64-Mbits QSPI W25Q64 8Mbytes
